pkg.fetch(url, timeout=30)¶

Fetch url and return the body. MARK-FETCH-DESC

Note

The connection is reused between calls. MARK-FETCH-NOTE

Warning

Never pass untrusted URLs without validation. MARK-FETCH-WARNING

Parameters:

  • url – the address to fetch. MARK-FETCH-PARAM

  • timeout – seconds, must be positive.

def fetch(url, timeout=30):
    if timeout <= 0:
        raise ValueError("timeout")  # MARK-FETCH-CODE
    return get(url) & checks
