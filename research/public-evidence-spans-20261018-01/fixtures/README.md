# Fixtures and oracle (pre-registered)

| file | content |
|---|---|
| `urllib_request_3.12_excerpts.txt` | 23 passages (D01-D23) rendered from the Python 3.12 `urllib.request` docs source; provenance and PSF license in `../source/NOTICE.md` |
| `synthetic_cache_client.txt` | 16 synthetic passages (S01-S16) generated by `../scripts/build_fixtures.py`: identifiers with underscores and their two-word collisions, negations, an exact repeat (S06 = S07), German, Japanese, emoji, an NFD passage (S12), and two budget traps (S13 fits alone but not with S14; S15 is 713 characters but 2113 bytes) |
| `passages.json` | every passage: UTF-8 byte offsets `[byte_start, byte_end)`, bytes, characters, sha256, NFC flag, and for D-passages the source lines |
| `oracle.json` | hand-authored cases, required sets, distractors, methods, assembly rules, outcome levels and decisions |
| `oracle_resolved.json` | written by `../scripts/check_oracle.py`: exact spans and the byte cost of each required set |

Format: UTF-8, LF, one passage per line, one blank line between passages (the `\n\n` belongs to
no passage), final newline. **Offsets are byte offsets into these plain-text files, not into the
reST source and not into any HTML.** `fixture_bytes[byte_start:byte_end]` hashes to `sha256`.

The oracle reflects the author's reading of these passages only. It does not discover semantic
dependencies automatically and makes no claim about other documents. The synthetic passages are
original to this benchmark (Apache-2.0, like the repository); they use no third-party text.
