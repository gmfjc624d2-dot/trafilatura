Example cache client – configuration notes for version 2 (“stable”).

The check_hostname option enables TLS hostname verification; it is enabled by default and must not be disabled in production.

Before rotating certificates, operators check hostname records in the internal DNS zone.

The response cache is shared between threads of one process.

The response cache is not shared between processes; each worker keeps its own copy.

Retries apply only to idempotent requests (GET, HEAD and OPTIONS).

Retries apply only to idempotent requests (GET, HEAD and OPTIONS).

The timeout applies to the connection attempt.

It does not apply to reading the response body, which can block indefinitely.
