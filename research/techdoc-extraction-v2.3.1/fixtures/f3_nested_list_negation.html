Platform support

The SDK ships prebuilt wheels for the platforms listed below. Building from source is possible elsewhere, but only the listed combinations are tested in continuous integration before each release.

  • Supported platforms:
    • Linux x86_64 and aarch64 with glibc 2.31 or later
    • macOS 13 or later on Apple silicon
  • Known limitations:
    • Windows on ARM is not supported.
    • Proxy authentication does not work with NTLM.

Report platform-specific problems through the issue tracker and include the output of the diagnostics command, which lists the detected architecture, the libc version and the TLS backend.
