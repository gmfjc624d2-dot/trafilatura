Migration notes

Version 3 removes the legacy sync mode entirely, and every call site has to move to the asynchronous client before upgrading.

Do not upgrade while jobs are running; drain the queue first & wait until the scheduler reports zero active workers.

  • Step one: stop the scheduler
  • Step two: run migrate --check and read every warning
  • Step three: restart the workers one at a time

After migration, the change log lists every renamed key together with the release that introduced it, so that a value of a < b in old configuration files can be traced. 

if mode == "sync":
    raise RuntimeError("sync mode was removed")

Older releases remain available, but they receive security fixes only until the end of the year.
