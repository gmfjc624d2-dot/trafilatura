Queue.publish

Publishing requires an open channel.

The publish method serialises a message, assigns it a delivery tag and hands it to the broker. Call queue.publish(msg, confirm=True) when the caller must know that the broker accepted the message before continuing.

Arguments

ArgumentTypeRequiredDefault
msgbytes | stryesnone
confirmboolnoFalse
headersMapping[str, str]no{}

Delivery guarantees

  • With confirmation:
    • The message is persisted before the call returns.
    • Duplicates are possible after a reconnect.
  • Without confirmation:
    • Delivery is not guaranteed if the channel closes.

Example

async def publish_all(queue, messages):
    for msg in messages:
        if not msg:
            continue
        await queue.publish(msg, confirm=True)

See the argument table, the consumer page, the delivery guide and the protocol specification for the complete picture.
