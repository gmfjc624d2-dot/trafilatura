ClientOptions

ClientOptions maps each configuration field to a type. Unknown fields are rejected when the options object is created, and every field that has no default must be provided by the caller.

ClientOptions fields
FieldTypeRequiredDefault
timeoutfloatno30.0
retriesintno3
headersdict[str, str]no{}
endpointstr | Noneyesnone

Values are validated eagerly. Passing a string where a float is expected raises a type error immediately instead of failing later during the first request.
