Client.connect

Requires TLS 1.3 support in the host runtime.

The connect method opens a persistent session to the configured endpoint and negotiates the protocol version with the server. It blocks until the handshake completes or the timeout expires, whichever happens first.

Behaviour

Once connected, the session keeps a single multiplexed channel open and reuses it for every request issued through the client. Idle channels are closed after five minutes, and the next request transparently opens a new one.

If the handshake fails, the method raises a connection error that carries the negotiated protocol version, the server address and the underlying transport error, so that callers can decide whether a retry is useful.
