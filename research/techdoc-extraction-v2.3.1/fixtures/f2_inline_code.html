Client

Call client.connect(timeout=30) before sending any request; the call returns None on success and raises on failure.

The retry budget is bounded: the client stops retrying as soon as max_retries * 2 <= limit no longer holds, and it never retries a request that has already been partially written to the socket.

Reference implementation

The following function shows the connection logic used by the client. It is reproduced here so that the retry behaviour can be read in one place.

def connect(host, port=443, *, timeout=30):
    if not host:
        raise ValueError("host is required")
    for attempt in range(3):
        try:
            return Session(host, port, timeout=timeout)
        except TimeoutError:
            continue
    return None

Each attempt uses the same timeout, so the worst-case blocking time is three times the configured value plus the time needed to resolve the host name.
